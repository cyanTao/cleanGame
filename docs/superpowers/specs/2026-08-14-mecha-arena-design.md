# 像素风机甲对战小游戏 — 设计文档

日期：2026-08-14
项目名：mecha-arena（机甲擂台）

## 1. 概述

一个复古像素风的横版机甲对战小游戏：两名机甲在擂台上移动、攻击、防御，HP 归零或倒计时结束时判定胜负。支持本地双人和人机（简单 AI）两种模式，Web 端运行。

- **技术栈**：Vite + Phaser 3（Arcade Physics），ES 模块化
- **视觉风格**：16-bit 精致像素风（SFC/GBA 质感：多级色阶、夜空渐变、城市剪影）
- **素材方案**：零外部文件，全部像素画以字符画二维数组 + 调色板定义，启动时程序化生成纹理
- **胜负机制**：单局定胜负

## 2. 玩法设计

### 2.1 对战形式

横版擂台，视口 960×540（16:9，`pixelArt: true` 像素完美渲染）。Phaser Arcade 物理：重力 + 单层地面平台。角色不可走出左右边界。

### 2.2 角色

两台机甲共用同一套字符画，通过调色板换色实现差异化：

| 机甲 | 定位 | 轻攻击伤害 | 移速 | 配色 |
|---|---|---|---|---|
| BLU-07「蓝影」(P1) | 均衡型 | 8 | 200 px/s | 蓝色系 |
| RED-99「赤焰」(P2 / AI) | 力量型 | 10 | 170 px/s | 红色系 |

### 2.3 操作

| 动作 | P1 | P2 |
|---|---|---|
| 移动 | A / D | ← / → |
| 跳跃 | W | ↑ |
| 轻攻击 | J | 1（数字键） |
| 防御（按住举盾） | K | 2 |
| 必杀技 | L | 3 |

标题界面选择模式：**本地双人** / **人机对战**（人机模式下 P2 槽位由 AI 控制）。

### 2.4 战斗数值（集中于 `src/config.js`，可调）

- HP：100
- 能量：0–100；轻攻击命中 +15，被击中 +8；满 100 才可释放必杀，释放后清零
- 轻攻击：前摇 120ms → 命中判定窗 100ms → 后摇 200ms；命中范围：面前矩形区域
- 必杀技：伤害 25，清空能量，强击退
- 防御：按住举盾，减伤 75%（向下取整），移速降至 30%；防御中受必杀技命中减伤 50%
- 命中反馈：受击闪白（tint）、击退、命中火花粒子、镜头微震

### 2.5 胜负机制（单局定胜负）

- 任意一方 HP 归零 → 立即判负
- 60 秒倒计时结束 → HP 高者胜；HP 相同则进入突然死亡（先命中者胜，双方 HP 置 1）
- 结算画面展示胜者，按 `R` 返回标题重开

### 2.6 UI（HUD）

- 顶部两侧：HP 条（受击时红色即时扣除 + 白色延迟条收缩）+ 能量条（满时闪烁提示可放必杀）
- 顶部中央：60 秒倒计时
- 开场提示："ROUND 1 — FIGHT!"
- 结算画面：胜者机甲立绘 + 名称 + `R` 重开提示

### 2.7 场景与动画

- 背景：夜空渐变（多层色带）+ 闪烁星星 + 远景城市剪影 + 地面平台（金属质感条纹）
- 机甲动画帧（字符画多帧）：待机（上下浮动）、行走（腿部 2 帧）、跳跃、攻击（手臂挥击 2 帧）、防御（举盾）、受击（后仰）、倒地
- 特效：命中火花粒子、推进器喷焰（跳跃时）、必杀冲击波（几何扩散图形 + 粒子）

## 3. 素材方案

全部程序化生成，无任何二进制资源文件：

1. **像素字符画**：每帧为一个字符串二维数组，字符映射调色板键（如 `O` 轮廓、`M` 中甲、`L` 亮甲、`E` 眼、`V` 能量核），存于 `src/data/sprites.js`
2. **TextureFactory**：`registerCharArt(scene, key, frames, palette)` —— 将字符画逐像素绘制到 canvas，注册为 Phaser 纹理与动画帧
3. **换色差异化**：两台机甲共用字符画，传入不同调色板（蓝系 / 红系）
4. **场景绘制**：夜空渐变用 Graphics 逐色带绘制；星星为 1×1 像素纹理随机分布；城市剪影用矩形组合
5. **特效**：Phaser 粒子系统 + 简单几何图形（必杀冲击波）

## 4. 代码架构

```
mecha-arena/
├── index.html
├── package.json            # vite + phaser 依赖
├── vite.config.js
└── src/
    ├── main.js             # Phaser.Game 配置（960×540, pixelArt: true, 场景注册）
    ├── config.js           # 全部战斗数值、键位、调色板常量
    ├── scenes/
    │   ├── BootScene.js    # 调用 TextureFactory 生成全部纹理后跳转 Title
    │   ├── TitleScene.js   # 标题画面 + 模式选择（1=人机 2=双人）
    │   ├── BattleScene.js  # 核心：回合流程、命中判定、HUD、胜负判定
    │   └── GameOverScene.js # 胜者展示 + R 重开
    ├── entities/
    │   └── Mecha.js        # 机甲实体：状态机 + Arcade 物理体 + 动画控制
    ├── systems/
    │   ├── InputSystem.js  # 双人键位 → 统一输入接口
    │   ├── AIController.js # 简单 AI，实现同一输入接口
    │   └── TextureFactory.js # 字符画 → Phaser 纹理/动画
    └── data/
        └── sprites.js      # 像素字符画数据（机甲各姿态帧、盾牌、火花等）
```

### 4.1 模块职责与接口

- **Mecha**：`new Mecha(scene, x, facing, palette, stats)`。内部状态机：`idle / walk / jump / attack / defend / hit / dead`（attack 含前摇-判定窗-后摇三段计时）。对外：`update(dt, input)`、`takeDamage(dmg, knockbackDir)`、`hp`、`energy`、`isDead`、`getHitbox()`。
- **统一输入接口**：`getState()` → `{ left, right, jump, attack, defend, special }`。**InputSystem（真实键盘）与 AIController（决策）产出同构对象**，Mecha 不感知输入来源——这是支持双人和 AI 的关键抽象。
- **InputSystem**：读取 `config.js` 键位表，`justDown` 边沿检测用于攻击/跳跃。
- **AIController**：决策节拍 ~200ms；行为规则（按优先级）：对方必杀/攻击且距离近 → 防御；自身能量满且近身 → 放必杀；距离远 → 移动接近；近身 → 概率攻击 / 概率跳跃；随机小概率后撤。性格参数（攻击欲、防御反应）进 config。
- **BattleScene**：创建双方 Mecha + 背景 + HUD；update 循环中执行：输入采样 → 实体更新 → 攻击判定窗开启时做矩形重叠检测（防御方需面向攻击者才减伤）→ 伤害/能量结算 → HUD 刷新 → 胜负判定 → 场景跳转。
- **TextureFactory**：字符画 → 纹理；提供 `makeGradient`（夜空）、`makeStars` 等场景绘制辅助。

### 4.2 数据流

```
键盘 / AI ──→ input 对象（统一接口）──→ Mecha.update() 状态机
                                            │
                 攻击判定窗开启（前摇结束）──→ BattleScene 矩形重叠检测
                                            │
                      伤害结算（防御分支）→ 能量结算 → HUD 更新
                                            │
                              HP 归零 / 倒计时结束 → GameOverScene
```

## 5. 错误处理

- 零外部资源加载，不存在资源 404/损坏风险；BootScene 生成纹理后自检关键纹理存在
- 回合结束（胜负已分）后立即锁输入，防止结算期间继续操作
- 突然死亡阶段强制 HP=1，避免平局死循环
- AI 决策异常时兜底为待机（永不抛出中断主循环）

## 6. 测试方案

- **单元测试（vitest）**：伤害计算（普通/防御/防御吃必杀分支）、能量结算与必杀门槛、倒计时胜负判定与突然死亡触发——均为纯函数，从 BattleScene 抽出 `resolveHit()`、`resolveTimerEnd()` 便于测试
- **手动测试清单**：
  1. 双人模式键位无冲突（P1 WASD+JKL / P2 方向键+123）
  2. 人机模式 AI 可接近、攻击、防御、放必杀
  3. 防御减伤数值正确、背向防御不减伤
  4. 必杀能量门槛、清空逻辑
  5. 60 秒倒计时判定与突然死亡
  6. R 重开流程完整（GameOver → Title → Battle）
  7. 动画状态切换无穿模（攻击/防御/受击/倒地）
